# Student Management System

## About

This is a Python-based Student Management System built as part of my Python learning journey.

The application allows users to add, search, update, delete, and display student records. Student data is stored persistently using JSON, so the records are available even after restarting the program.

## Features

- Add Student
- Search Student by Registration Number
- Update Student Details
- Delete Student
- Display All Students
- Input Validation
- Exception Handling
- JSON Data Persistence

## Technologies Used

- Object-Oriented Programming (OOP)

## Data Persistence

Student data is stored in students.json.

The application converts Student objects into JSON-compatible dictionaries when saving and reconstructs Student objects when loading.

## How to Run

Make sure Python is installed.
Open the project folder in a terminal.
Run:
python main.py
Use the menu to manage student records.
